REA Projekt

Samla dina "research engineerade" appar, produkter och tjänster. Projekten sparas som issues i ditt eget GitHub-repo.

Anslutning till GitHub

Token behöver bara läs- och skrivrättighet för Issues i just det repot. Den sparas enbart i den här webbläsaren (localStorage) och skickas bara till api.github.com.

Nytt projekt

Analysen körs av din agent med REA installerat. Sidan skapar projektet och en färdig prompt.

Mina projekt

REA används för lagliga syften: analys av programvara du äger eller har tillstånd att undersöka. Se morluto/rea för installation (npx rea-agents setup) och ansvarsfriskrivning.
